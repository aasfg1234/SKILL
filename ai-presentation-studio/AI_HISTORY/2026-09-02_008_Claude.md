並在面板底部說明「允許彈出式視窗後再按一次 N 就會開成獨立視窗」。

## 4. 技術決策

### ⚠️ 已確定的設計決策

1. **編輯器用「同畫面面板」，匯出檔用「獨立視窗」。**
   兩者用途不同：編輯器是排練，匯出檔才是正式簡報。
   不要把編輯器也改成開獨立視窗，那會讓排練變麻煩。

2. **獨立視窗的內容由主視窗直接寫入 DOM，不用任何訊息通道。**
   `window.open('')` 得到的 `about:blank` 會繼承主視窗的來源，
   所以 `file://` 直接雙擊開啟也能操作子視窗。
   **不要改成 BroadcastChannel 或 localStorage 同步**，那些在 `file://` 上不可靠。

3. **彈出視窗被擋時一定要有退回方案。**
   目前退回同畫面面板並顯示說明。不要拿掉這個分支。

4. **備註用 `data-notes` 屬性帶出去，不用 JSON 區塊。**
   備註內容如果含有 `</script>` 會破壞 JSON 區塊；屬性走 `escapeHtml` 比較安全。

5. **匯出檔裡的計時器格式是手寫的一份簡化版。**
   匯出的 HTML 不能 import TypeScript，所以 `elapsedText()` 在
   `navigationScript` 裡另外寫了一份。改格式時**兩邊都要改**：
   `src/model/presenter.ts` 的 `formatElapsed` 與 `renderHtml.ts` 的 `elapsedText`。

## 5. 問題與解決方式

**問題**：想在瀏覽器裡測匯出的簡報，卻發現 `dist/AI-Presentation-Studio.html`
是「編輯器本身的單檔版」，不是匯出的簡報。

**解決**：用 esbuild 把 renderer 打包成暫時的 mjs，產生一份真的匯出檔來測，
測完刪除暫存檔。

**下一個 AI 注意**：`dist/AI-Presentation-Studio.html` = 編輯器；
`final-presentation.html` = 匯出的簡報。兩者不同，不要搞混。

**問題**：測試環境的瀏覽器面板會擋掉彈出式視窗。

**結果**：**獨立視窗那條路徑沒辦法在這個環境驗證**，只驗到了退回方案。
已確認 `window.open` 在該環境回傳 `null`，因此確定是環境限制而非程式錯誤。
獨立視窗請在真正的 Chrome／Edge 上實測。
