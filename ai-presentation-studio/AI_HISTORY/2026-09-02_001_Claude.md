## 4. 技術決策

### ⚠️ 已確定的設計決策

1. **紀錄系統放在 `ai-presentation-studio/`，不是 Git repo 最上層。**
   原因：repo 最上層混雜多個無關的 zip 檔與 HTML 檔，不是這個專案的家。
   下一個 AI 請到 `ai-presentation-studio/AI_PROTOCOL.md` 讀規則，到 `AI_HANDOFF.md` 找接力狀態。

2. **未提交的改動採「原樣存檔」，不重寫、不重構。**
   原因：協議第十二條，不覆蓋另一個 AI 的工作。
   該批改動的作者無法從紀錄證實。commit 訊息已明確標註「無接力紀錄可證明作者」。

3. **`.claude/worktrees` 加入 `.gitignore`。**
   原因：本次 session 的 worktree 實體位於 `ai-presentation-studio/.claude/worktrees/` 之下。
   不排除的話，`git add` 會把整個副本吃進版本控制。

### 沿用前人已定、不要推翻的決策

以下來自 commit `64ff752` 與 `397645c`，是專案的地基：

- **第一版完全不串接任何 AI API。** 改用 AI Handoff Package（一包普通檔案）交給外部 AI。
- **Local-first / Offline-first。** 沒有後端、資料庫、帳號、雲端同步。資料存 localStorage。
- **Model / Renderer / Editor 三層分離。** Renderer 是純函式，不依賴 React。
- **所有 ID 穩定唯一，禁止用陣列索引定位。**
- **資料協定版本化：** `ai-presentation/v1`、`ai-presentation-patch/v1`。
- **匯入內容一律 sanitize。** 移除 `<script>`、`on*` 事件屬性、`javascript:`、`<iframe>` 等。
- **交付形式是單一 HTML 檔** `dist/AI-Presentation-Studio.html`，雙擊即可用。
- **開發模式與交付模式分離。** `vite-plugin-singlefile` 只在 `command === 'build'` 時載入。
