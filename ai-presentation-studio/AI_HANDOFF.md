## 重要注意事項

1. **專案有兩份副本。** 動手前先跑 `git worktree list` 與 `git status`，確認自己站在哪一份、哪一個分支。弄錯會讓工作消失在另一份副本裡。所有開發請在本體 `ai-presentation-studio/` 進行。
2. **不要把 `factory.ts` 的 z 預設值改回 1，也不要把 `element.z || nextZ(...)` 改成 `??`。** 兩者都會讓 BUG-1 復發。`0` 代表「尚未指定層次」。
3. **所有 z-index 一律從 `src/lib/layers.ts` 取。** 不要在元件裡寫死數字，也不要用 `z-[...]` 類別。`layers.test.ts` 會擋住順序被破壞。
4. **不要動 `demo.ts` 既有的 z 值。** 示範簡報的層次是刻意排的。
5. **不要直接刪掉「重疊警告」。** 它有用，只是判斷門檻太寬，要改的是門檻不是功能。
6. **改動 UI 行為時，單元測試之外一定要真的開瀏覽器操作一次。** Session 003 遇過函式測試全過、但根本沒接上的情況。
7. **重疊警告的門檻常數是 `Canvas.tsx` 的 `OVERLAP_COVER_RATIO`（0.6）。** 不要改回「相交就警告」。
8. **右鍵選單的內容由 `src/lib/contextMenu.ts` 的純函式決定。** 要增減項目改那裡並補測試。
9. **確認對話框一律用 `editorStore.confirm()`。** 不要再用 `globalThis.confirm`。
10. **版型的每個元素都必須明確指定 `z`。** 版型元素不經過 `addElementToSlide`，忘了給會全部變成 0。`layouts.test.ts` 會擋。
11. **新增版型時，`Dialogs.tsx` 的 `LayoutPreview` 縮圖要一起加。** 否則新版型會顯示成空白縮圖。
12. **圖片一律轉成 data URL 存進簡報。** 這是維持「單檔可離線開啟」的必要取捨。
13. **驗證即時狀態請看畫面與 DOM，不要看 `localStorage`。** 存檔是延遲寫入的，會落後。
14. **替既有型別新增必填欄位時，務必處理舊存檔沒有該欄位的情況。** Session 006 已經因此出過一次錯：新增 `listStyle` 後，舊存檔全部被誤判成編號清單。判斷式要寫成「等於某些值才算開啟」，不要寫成「不等於某個值就算開啟」。
15. **表格支援儲存格合併，欄寬一律用比例存。** 不要改成存像素寬。
16. **搜尋取代的範圍包含標題、備註、文字元素與表格儲存格。** 永遠不改 AI Prompt。
17. **含反斜線跳脫的程式碼不要用 shell heredoc 傳。** 跳脫字元會被吃掉，產生無法編譯的檔案。
18. **所有字型堆疊一律以拉丁字型開頭。** 中文字等寬，跑版來自英文與數字。`fonts.test.ts` 會擋住違規。
19. **只提供 Windows 與 macOS 都有、尺寸一致的拉丁字型**（Arial／Times New Roman／Courier New）。不要加只有單一系統有的字型。
20. **編輯器介面的字型不要跟著改。** 介面字型不會被匯出，改它是多餘的改動。
21. **跨字型、跨系統的版面問題一律實測，不要用直覺推論。** `document.fonts.check()` 連假字型都回報 `true`，不可用來判斷字型是否安裝。
22. **`dist/AI-Presentation-Studio.html` 是編輯器本身的單檔版，不是匯出的簡報。** 匯出的簡報是 `final-presentation.html`。不要搞混。
23. **匯出檔的講者視窗靠主視窗直接寫入子視窗 DOM，不用任何訊息通道。** 不要改成 BroadcastChannel 或 localStorage 同步，那些在 `file://` 上不可靠。
24. **計時器格式有兩份**：`model/presenter.ts` 的 `formatElapsed` 與 `renderHtml.ts` 裡手寫的 `elapsedText`。匯出檔不能 import TypeScript，所以必須這樣。改格式時兩邊都要改。
25. **換頁按鍵對照也有兩份**：`model/presenter.ts` 的 `previewStepFromKey` 與 `renderHtml.ts` 的 `stepFromKey`。同上，兩邊都要改。
26. **「結束連續編輯」統一在 `setEditingText(null)`／`clearSelection()`／`selectSlide()` 三個入口。** 不要改成在每個編輯欄位掛 `onBlur`，表格會變成每移動一格就切一個復原點。
27. **多份簡報用 localStorage，容量約 5～10 MB。** `upsertDeck` 的回傳值一定要處理，存不下時要提示使用者。
28. **`src/lib/layers.ts` 是 z-index 常數，`src/model/layerList.ts` 才是圖層清單。** 名字很像，不要弄混。
29. **讀程式碼推論出來的症狀，一定要實際跑一次確認。** Session 008 與 009 各發生過一次判斷錯誤。
30. **不要對單一檔案跑 prettier。** 這個專案沒有 prettier 設定檔，會產生與其他檔案不一致的引號風格。
31. **「隱藏未完成的 AI 元件」是簡報層級設定，必須同時影響匯出檔。** 備註不受它影響，一律匯出，講者檢視才有東西可看。
32. **搜尋取代永遠不動 AI 元件的 Prompt。** 那是交給外部 AI 的指示，被批次取代會直接改壞產出。
33. **切換投影片比例不會自動重排元素。** 這是刻意的，自動重排更容易把版面弄壞。
34. **表格合併用 `merges` 陣列記錄矩形範圍，`cells` 永遠是完整的二維陣列。** 不要改成在 `cells` 裡挖洞。
35. **增刪列欄時合併會「縮小」而不是「消失」，縮到一格才自動取消。** 這比整個丟掉更貼近使用者意圖。
36. **圖表產生的是 SVG 字串，編輯器與 Renderer 共用 `buildChartSvg`。** 不要為了方便在編輯器另外寫一份 React 版，兩邊會走鐘。
37. **圖表支援多數列。** 圓餅圖只使用第一組數列。
38. **測試失敗時先判斷是實作錯還是測試的假設錯。** Session 011 就是測試的假設比較差。
39. **`axisRange` 是座標軸的唯一來源。** 間距用 1／2／5 × 10ⁿ 自動決定，一定包含 0。不要再寫「單位至少 10」這種寫死規則，對小數是錯的。
40. **圖表的文字寬度一律用 `estimateTextWidth` 估算。** Renderer 沒有 DOM，不能用瀏覽器量測。
41. **標籤放不下的順序：先縮字級（最多六成），再轉 -35 度。** 不要改成截斷文字。
42. **圓餅圖圖例放右側直向排列。** 橫向平均分佈在標籤長時一定重疊。
43. **圖表資料貼上是「取代」不是「附加」。**
44. **讀取圖表數列一律用 `seriesOf(el)`。** 不要直接讀 `el.series` 或 `el.values`，那是舊檔相容的唯一防線。
45. **`values` 是舊版欄位，新程式只寫 `series`。** 更新時記得把 `values` 設成 `undefined`。
46. **`chart.ts` 是純資料層、`chartDraw.ts` 是純繪圖層。** 不要把繪圖程式搬回 `chart.ts`。
47. **橫向長條圖的類別名稱一律水平靠右，不縮字也不旋轉。** 那正是它存在的理由。
48. **大段、含反斜線跳脫的修改，先把腳本寫成檔案再執行，不要用 shell heredoc。** 已經反覆踩到五次。
49. **不要串接真的 AI API。** 第一版刻意不串。要改必須先問使用者。
50. **不要動 `src/model/sanitize.ts` 的白名單清理。** 那是唯一的 XSS 防線。
51. **完整的「已確定設計決策」清單在 `AI_PROTOCOL.md` 第十二節，以及 Session 003～013 的第 4 節。** 推翻任何一項之前，先讀它。
52. **匯出簡報的 `#aps-stage` 必須保留 `flex:0 0 auto`。** 拿掉會在高縮放比例下再次壓窄投影片。
53. **講者視窗的下一頁預覽使用同一份投影片 HTML。** 不要另寫一套縮圖 Renderer。
54. **每個 Session 結束時自己提交 Git，不要留給下一個 AI。** GPT Session 014～018 連續五次沒提交，933 行工作長期沒有還原點。接手時先跑 `git status`，若前一個 AI 沒提交，先提交再開始新工作。
55. **含反斜線的修改，一律用檔案工具把 Python 腳本寫到 scratchpad 再執行。** 即使用 `<<'EOF'` 這種「不展開」的 heredoc，反斜線仍然會被吃掉（Session 020 再次踩到）。腳本裡每一項替換都要 `assert count == 1`。
56. **投影片層級的規則一律走 `src/model/deck.ts`。** `visibleSlides()` 決定哪些頁要播、`slideNumberFor()` 決定頁碼。畫布、縮圖、播放、匯出四邊都用同一份，不要各自再判斷一次 `slide.hidden`。
57. **`previewIndex` 數的是「沒有被隱藏的第幾張」，不是 `slides` 的陣列位置。** 動播放邏輯時要記得換算回原本的索引才能取母片與背景。
58. **條列的縮排層級存在文字本身的行首 Tab，沒有另外的欄位。** 這樣複製貼上與復原都會跟著走。讀取一律用 `formatListLines()`，不要自己 split。
59. **圖形只有 `rect` / `ellipse` / `line` / `shape` 四種型別。** 三角形、菱形、箭頭、星形、對話框都是 `shape`，座標由 `src/model/shapes.ts` 的 `shapePoints()` 產生，不要為每一種形狀再開一個型別。
60. **圖片裁切用 `cropImageStyle()`，外框必須保持 `overflow:hidden`。** 有裁切時圖片一律 `object-fit:fill`，因為使用者已經自己框好範圍。
61. **裁切樣式一定要帶 `max-width:none` 與 `max-height:none`。** 全域的 `img{max-width:100%}`（Tailwind 預設）會把放大的圖片壓回框寬，看起來像「圖片只是被平移、右邊留白」。Session 021 踩過一次。
62. **瀏覽器自動化切不了投影片。** 縮圖用 `setPointerCapture` 做拖曳，合成點擊不會觸發 click。要在自動化裡換頁，用 `find` 取得縮圖的 ref 再點，不要用座標。
63. **編輯中的文字元素不畫本體，只畫覆蓋層。** 兩層一起畫一定會出現對不齊的殘影（Session 024 修過）。覆蓋層是「定位殼 + 內層 contentEditable」兩層，外殼用 flex 做垂直對齊。
64. **編輯覆蓋層必須 `stopPropagation()` 掉 pointer 事件。** 不擋的話拖曳選字會冒泡到畫布變成框選，編輯也會中斷。**不要改成 `preventDefault`**，那會讓反白與游標定位一起失效。
65. **文字的可點範圍由 `[data-aps-text]` 的 span 決定。** 只有壓在這個 span 上才是 I 字型游標、才會點一下進入編輯；方塊的空白處維持搬移。改文字排版時要保留這個 span。
66. **文字點一下就進入編輯，不是雙擊。** 判斷條件在 `Canvas.tsx` 的元素 `onClick`：拖動超過 4 像素、按著 Shift／Ctrl／Cmd、元素屬於群組、或工具不是「選取」時都不觸發。改動搬移或加選時要一起確認這四個條件還在。
67. **矩形、圓形、線條與五種基本圖形集中在工具列的「圖形」選單。** 不要再拆回獨立按鈕。矩形／圓形／線條走 `setTool()`，其餘走 `setShapeKind()`。
68. **裁切會改變元件的大小與位置，不只是改保留範圍。** 完成裁切時元件框會縮成使用者框起來的那一塊（PowerPoint 的行為）。**不要改回「框不動、內容拉滿」**，那會讓裁切後的圖變形。
69. **裁切的兩個純函式 `imageRectOf()` 與 `croppedBox()` 互為反運算，拖框與屬性面板的數字欄位都要走它們。** 只改一邊會讓兩種操作結果不一致。
70. **畫布上所有控制點都要設 `zIndex: LAYER.canvasOverlay`，可點範圍要 20 像素。** 視覺大小維持 9 像素，用透明的大外框撐開可點範圍（Session 025 修過縮放控制點）。
71. **剪貼簿圖片要同時看 `clipboardData.files` 與 `clipboardData.items`。** 只看其中一邊會有截圖貼不上的情況（Session 026 修過）。
72. **畫布的貼上監聽器遇到輸入框就放手。** 判斷條件是 `e.defaultPrevented`、正在編輯文字、事件來源是 `input`／`textarea`／`select`／`contenteditable`。**新增任何「貼上就自動做某件事」的功能時，這三道判斷都要留著**，否則貼一次會同時做兩件事（例如圖表欄位會多冒出一個表格）。
73. **沒有 Tab 的文字不轉表格。** `parsePastedTable()` 只在文字含 Tab 時回傳表格，貼普通文字不應該冒出表格。上限 50 列 × 20 欄。
74. **畫布上所有「外框類」的東西都必須設 `zIndex: LAYER.canvasOverlay`。** 元素外層固定是 `zIndex:1`，而 `z-index:1` 一定畫在 `auto` 上面。忘了設就會被大面積元素蓋掉（Session 022 修過選取框、對齊輔助線、框選矩形）。不要把元素外層改成更大的數字。
75. **Mock AI（假生成）已經刪除，不要再加回來當「全 AI 生成」「AI 生成單頁」的入口。** 兩個入口一律是「下載壓縮檔 → 交給外部 AI → 匯入結果」，跟 AI 元件既有的 `匯出 AI Package`／`匯入 AI 完成結果` 是同一種模式，實作在 `src/ai/handoffPackage.ts`。`SettingsForm`／`OutlineEditor` 這兩個表單元件放在 `src/components/FullAiFormParts.tsx`，供 `ExternalFullAiDialog.tsx` 重用，不要搬回舊的 `FullAiDialog.tsx`（已刪除）。
